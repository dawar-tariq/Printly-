The `orders` publication contains all 26 current columns (including personal, payment and token fields), has no publication row filter, and enables insert/update/delete; the table's replica identity is default. Table RLS is enabled but not forced. This is a release blocker and a potential production risk, not confirmation of a production leak. No production order rows were read and no production change was made.
